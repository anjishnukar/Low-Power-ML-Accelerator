Low-Power ML Accelerator

01 · Overview

What is a Systolic Array?

Imagine a grid of tiny calculators (Processing Elements, or PEs) arranged in rows and columns. Each calculator holds one weight and performs one multiply-accumulate per cycle.

The systolic dataflow

Weights stay in place (stationary). Input activations stream through the array, and partial sums accumulate — like an assembly line where every PE is busy every cycle.

Why it is fast & low power

Every PE works in parallel on one multiply-accumulate per cycle. The 3-stage pipeline (multiply → add → accumulate+activate) allows a new input every cycle while results are still in flight.

Because neural activations are often sparse, a zero-skipping clock gate disables the clock when weight or activation is zero — saving dynamic power with no accuracy loss.

02 · Architecture

System Architecture

From host DMA down to the activated output stream — data passes through a ping-pong SRAM buffer, the systolic array, and an activation unit.

Ping-pong buffering

Two SRAM banks alternate roles: while Bank A is written by the host, Bank B is read by the array. On a swap signal the roles flip, hiding memory latency.

Per-PE responsibilities

Each PE holds a weight register, an activation register, a 3-stage pipelined MAC, a clock gate, and an activation function unit (ReLU, quantized Tanh, or linear).

04 · Datapath

The Per-PE Pipeline

One PE runs a 3-stage multiply-accumulate pipeline: multiply, add, accumulate + activate.

STAGE 1

Multiply

product = weight × activation (INT8 * or FP16 multiplier)

→
STAGE 2

Add

sum = product + partial_sum_from_above

→
STAGE 3

Accumulate + Activate

accum = sum → activation (ReLU / Tanh / Linear)

Zero-skip: if weight or activation is 0, the clock gate turns off the multiplier clock — the PE skips the multiply but keeps the dataflow.

05 · Low Power

Low-Power Features

Dynamic power is the dominant cost in edge accelerators; this design attacks it at three levels.

Zero-skipping (clock gating)

Each PE checks: is my weight or activation zero? If yes, the clock to the multiplier/adder stages is gated off.

weight=0 or activation=0 → clk_en=0 → gclk=0 → MAC stages don't toggle

Latch-based clock gate

Uses a latch-based clock_gate cell (not an AND gate) to prevent clock glitches — the standard approach in real ASICs.

UPF power domains

DomainContentsVoltage RailNotes
PD_COMPUTEPE gridVDD_COMPUTECan be voltage-scaled
PD_MEMORYSRAM buffersVDD_MEMHigher voltage for stability
PD_CTRLControl logicVDD_CTRLAlways on

Level shifters between compute/memory domains, retention registers for PE accumulators, and a power switch to gate VDD_COMPUTE during idle periods.

The same systolic array supports two quantization modes via the USE_FP16 parameter.

    15        14:10             9:0

07 · Verification

Co-Simulation Strategy

A Python golden model generates expected vectors; the RTL testbench drives the array and compares.

Python NumPy Model                SV / C++ Testbench
        │                                │
        │  Generate random W, A        │
        ├──────────────────────────────►│
        │  Compute Y = f(W × A)        │
        │                                │
        │  Write expected Y to hex    │
        ├──────────────────────────────►│
        │                                │  Drive W, A into DUT
        │                                │  Read Y from DUT
        │                                │  Compare Y vs expected
        │                                │  Report pass/fail

Test cases: random INT8 + ReLU, random INT8 + Tanh, all-zero inputs (zero-skip), throughput check.
